Features:

Accepts integer and decimal coordinates.

Detects invalid numerical input.

Checks for duplicate vertices.

Detects collinear points.

Calculates and displays the orthocentre rounded to two decimal places.

Current Limitations:

The current slope-based method does not handle every valid triangle. In particular, triangles with horizontal or vertical sides may cause division-by-zero errors.

How to Run:

Make sure Python 3 is installed.

Download orthocentre.py.

Run the file using Python.

Enter the x- and y-coordinates of the three vertices when prompted.

Future Improvements:
